# 統家便利商店 自動補貨系統（課堂示範版）

系統依「最近 7 天移動平均＋20% 安全庫存」計算建議補貨量，最後數量由店長確認或修改後送出。

## 執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 檔案

| 檔案 | 說明 |
|---|---|
| `app.py` | Streamlit 介面（首頁、自動補貨清單、商品明細、補貨單確認） |
| `replenish.py` | 假資料與補貨計算、狀態判定 |
| `.streamlit/config.toml` | 白色簡約主題 |

## 補貨公式

```
預測明日銷售 = 四捨五入( 最近 7 天銷售總和 ÷ 7 )
安全庫存     = 四捨五入( 預測明日銷售 × 20% )
建議補貨量   = max( 0, 預測明日銷售 + 安全庫存 − 現有庫存 )
```

狀態（由上往下判定）：特殊訂單（店長量 > 預測 × 3）→ 低庫存（庫存 < 預測 × 50%）→ 建議補貨 → 正常。

假設：今晚下單、明早到貨。錄影重來時，按側邊欄「重設示範資料」即可回到初始狀態。
